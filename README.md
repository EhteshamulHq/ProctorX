# ProctorX

ProctorX is a production-style Online Assessment and Remote Proctoring Platform built using the MERN stack.

## Project Goals

The platform will provide:

- Online assessments
- Candidate management
- Question bank management
- Exam execution
- Remote proctoring
- Real-time monitoring
- Assessment results and reports

## Technology

The project is planned around:

- MongoDB
- Express.js
- React
- Node.js

Exact dependency versions will be determined from the actual repository/environment during project initialization.
